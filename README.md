# Cpp Bank Management System | نظام إدارة بنك بلغة C++

A console bank management system written in C++. The program starts from a login screen (`clsloginscreen`) and keeps showing it until the user exits.

نظام إدارة بنك بلغة C++ يعمل من سطر الأوامر. يبدأ البرنامج بشاشة تسجيل الدخول (`clsloginscreen`) ويعيد عرضها حتى يخرج المستخدم.

## Files | الملفات

- `BankSystemProject.cpp` — program entry point (`main`).

## Notes | ملاحظات

- The rest of the project files (the `cls*.h` headers) are being added.
